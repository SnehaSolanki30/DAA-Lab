# Part 1 - Trace It Yourself

### Input
```
[8, 3, 15, 6, 2]
```

### Output
- Largest Number = **15**
- Sorted Array = **[2, 3, 6, 8, 15]**
- Comparisons Made = **4**

### Dry Run

| i | A[i] | Max | Comparisons |
|---|------|-----|-------------|
| 1 | 3 | 8 | 1 |
| 2 | 15 | 15 | 2 |
| 3 | 6 | 15 | 3 |
| 4 | 2 | 15 | 4 |

### Explanation
The program scans the array to find the largest element and then sorts it using Bubble Sort.
